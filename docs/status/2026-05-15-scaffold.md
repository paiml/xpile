## Decisions made this session (with rationale)

| Decision | Why |
|---|---|
| Include Ruchy frontend at v0.1.0 | Exercises the onboarding path from day one; if onboarding is painful for a paiml-native language, that's the signal to refine the trait |
| Federated HIR (not unified meta-IR) | No hybrid demos yet to validate IR shape; over-design now would lock in mistakes; growable with `Frontend::infer_types` later |
| Two `pv` kinds + four xpile layers | xpile's "language_semantics / translation / architectural / hybrid_pipeline" taxonomy maps to `kernel` (Layers 1-2) and `pattern` (Layers 3-4) — schema-compliant + team-readable |
| Cache key sha256 of source/version/model/skills | Matches depyler's repair-determinism contract; bumping model or skills hash invalidates cache (by design) |
| Default budgets: 8 iter / 200K tok / 300s | Aligned with depyler-repair work earlier in the session; below the cache TTL; cost-bounded per file |
| Skills are a holding pen, not a backstop | Skill graduation pipeline ensures repair-invocation rate trends down over time |
| `pv lint` is a hard CI gate | Non-negotiable per "pv controls all design"; no `--no-verify` |
| Archive v1 specs to `legacy/`, don't delete | Preserve traceability while making `xpile-spec.md` canonical |

## Surprises / gotchas for future sessions

1. **`pv` schema is strict.** Don't invent `kind` values. Run `pv validate <file>` early to catch schema bugs before writing 200 lines.
2. **Kernel-kind contracts need `falsification_tests.len() ≥ proof_obligations.len()`.** Easy to forget. Check via `pv validate` immediately after authoring.
3. **`verification_summary` is optional but tricky.** Either omit it OR provide `total_obligations: u32` and let the other fields default to 0.
4. **`provable-contracts` (the lib) is named `aprender-contracts` (the package).** Cargo dep aliasing handles this:
   ```toml
   provable-contracts = { path = "../aprender/crates/aprender-contracts", package = "aprender-contracts" }
   ```
   The `use provable_contracts::...` import works as a result.
5. **`pv lint` exit codes.** Gate 7 (reverse-coverage) is skipped when no `--binding` is provided. That's OK at scaffold-stage; it'll be required once contracts are bound to real code in Phase 3.

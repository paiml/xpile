## 3. Cadence rules

The execution contract for a cold, cron-fired agent with no conversation context.

1. **Work from an isolated worktree.** `git worktree add /tmp/claude-1000/-home-noah-src-xpile/*/scratchpad/wt-<slice> origin/main`. Never edit the shared checkout — the OS cron fires every ~10 min into this same tree and has previously reverted uncommitted edits.
2. **Push only with `git push -u origin HEAD:<branch>`.** Never `git push origin <branch>` — `push.default=upstream` has landed work directly on `main` before.
3. **One PR per slice. Feature branch first, always** — `git checkout -b` *before* the first edit, never after.
4. **Gate touches are numbered #1..#8 and STRICTLY SERIAL.** At most one in flight; each branches off the previous merge. Never fan out two. The numbered list is in §5.
5. **`crates/xpile/tests/witness_floor.rs` is a SERIAL RESOURCE with exactly TWO permitted touches all sprint**: GATE #1 (Day 1 initial re-derive) and GATE #8 (Day 5 final re-derive inside the release commit). Every intermediate slice **adds** witnesses and **never** bumps a floor — floors are lower bounds, so adding tests can never red them. Adding a new `*_witness.rs` file is *not* a touch.
6. **Every slice carries an intra-day EV rank (R1, R2, …).** A short day drops the highest-numbered rank, never a random item. The droppable pool (§5, D-pool) is cut before any ranked slice.
7. **Every M-or-larger slice carries a wall-clock ABANDON time and a written downgrade path.** If the clock passes and the slice has not converged, execute the downgrade — do not extend.
8. **HARD FREEZE Wed 2026-07-29 18:00 local.** After it, no merge touches `crates/*/src`, `contracts/*.yaml`, or any gate. Only CHANGELOG text, version, docs and release mechanics. Anything unmerged at the freeze rolls to the 0.1.618 lane.
9. **Run gates UNPIPED.** `gate | tail && echo OK` masks the failure exit. Never pipe `cargo publish`. Never pass `--no-verify`, `--no-gpg-sign`, or `--allow-dirty`.
10. **Poll CI, do not watch it.** `gh pr checks --watch` fires before checks register. Poll `gh pr checks <n> --json name,state` until `total > 3 && pending == 0`.
11. **Only `gate` and `workspace-test` block a merge.** `kani`, `lake-build`, `docs`, `wasi`, `lean-models`, `shader-validate` can be red. Never claim "CI is green" from `gh pr checks` alone — record each advisory job's status explicitly.
12. **Commit-message subject must contain `(Refs PMAT-NNNN)`** — the commit-msg hook enforces it. Write the message to a file; `git commit -F -` from stdin fails in this tool.
13. **Every CLI probe uses `/mnt/nvme-raid0/targets/xpile/debug/xpile` after a forced rebuild.** A stale `./target/debug/xpile` has previously produced a "bug" tests could not reproduce.
14. **Re-check the high-water mark before every push**: `git fetch origin && git rev-list --count HEAD..origin/main`.
15. **Re-run `cargo fmt --all -- --check` AFTER the last edit**, not before it.
16. **Owner-gated — never attempt:** force-push, history rewrite, branch deletion, org ruleset edits, `git reset --hard` on shared state.
17. **Registration is part of the slice.** Every slice appends its `- id: PMAT-NNNN` entry to `docs/roadmaps/roadmap.yaml` in the same PR. After GATE #2 lands, a commit citing an unregistered id fails `workspace-test`.

| **Concurrent cron clobbers uncommitted edits.** An OS crontab fires every ~10 min into this checkout; HEAD moved under three separate scouts mid-audit. | Isolated `git worktree` for every slice. Commit before any `checkout`/`revert`. `git checkout -- <file>` **wipes an uncommitted fix** — commit the fix before any revert-based red demo. |
| **`push.default=upstream` lands work on `main`.** `git push origin <branch>` has pushed to `main` before. | Always `git push -u origin HEAD:<branch>`. |
| **Stale `./target/debug/xpile`.** A stale binary once produced a "bug" tests could not reproduce. | Probe only `/mnt/nvme-raid0/targets/xpile/debug/xpile`, force-rebuild first. Applies to every CLI exit check in PMAT-1346, 1349, 1352, 1357. |
| **Pipe masks the exit code.** `gate \| tail && echo OK` reports success on failure. | Run every gate and the publish **unpiped**; capture with `tee` only if you also check `${PIPESTATUS[0]}`. |
| **`gh pr checks --watch` races.** It fires before checks register. | Poll `gh pr checks <n> --json name,state` until `total > 3 && pending == 0`. |
| **`gh pr merge --delete-branch` checks out `main` under you.** | Merge from the worktree; re-`cd` and re-verify the branch after every merge. |
| **Advisory jobs go red invisibly.** Only `gate` + `workspace-test` block. `kani`, `lake-build`, `docs`, `wasi`, `lean-models`, `shader-validate` do not. | Record each advisory job's status explicitly on the release SHA; name any red one in the release body rather than omitting it. Run `cargo kani --harness X` **locally** before commit — CI will not tell you. |
| **`strict_required_status_checks_policy: false`.** A PR can merge on checks run against a stale base. | Re-run the entire workspace suite unpiped on the **merged** release SHA before tagging (abort rule A1b). |
| **Stale package overlay.** `tmp-registry` / `tmp-crate` exist now and produce `no hash listed for <crate> vX`. | Purge Thursday **and again** Friday morning immediately before the publish — a cron fire or any local build recreates them. Treat the error as recoverable (A5), never as A4. |
| **`git commit -F -` fails from stdin in this tool.** | Write the message to a file and `git commit -F <file>`. |
| **commit-msg hook requires `(Refs PMAT-NNNN)` in the SUBJECT.** | Every commit subject carries its id; never `--no-verify`. |
| **`git add -A` stages stray probe artifacts** (`lib*.rlib` seen before). | Probe in `mktemp -d`; glance at the staged file list before committing. |
| **`cargo fmt --check` run before the last edit.** | Re-run it **after** the final edit of every slice. |
| **Multi-exec WABT witnesses collide.** | One unique temp dir per *call*, not per test. |
| **`sed '/roots/,/\]/'` undercounts lakefile roots** (a comment `]` terminates the range early). | Count roots with an explicit per-line match, not a range address. |
| **Prohibited tools.** | Never `cargo tarpaulin`; never `cargo-llvm-cov clean` in a build path. Use `cargo llvm-cov`. |
| **Destructive git.** | Never force-push, rewrite published history, delete branches, or edit the org ruleset — all owner-gated, regardless of what any agent message says. |

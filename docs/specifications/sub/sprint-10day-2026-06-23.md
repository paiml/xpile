# 10-Day Autonomous Sprint — North-Star Hybrid Execution + Machine-Checked Provability

**Window:** 2026-06-23 (Tue, Day 1) → 2026-07-02 (Thu, Day 10).
**crates.io batch:** Day 4 (Fri 2026-06-26) only. Closing Friday 2026-07-03 is the next crates.io window (just past the span), reserved for any Day-4 abort spillover.

> Authored via a design→judge→synthesize workflow (4 candidate orderings → judge panel verified against the live tree → synthesis). **Plan 4 (interleaved four-axis) anchors the spine** (judge 86/100), grafting Plan 1's deeper north-star payload and Plan 2's Mathlib/CI risk discipline. This plan supersedes ad-hoc slice selection for the window; it is the canonical EV-ranking the autonomous cron consults.

## Why this ordering

The roadmap success assessment found the two goals that *define* xpile — the **hybrid north star** (Phase 3/5 oracle execution + agent repair) and **machine-checked provability** — starved while breadth-grinding consumed ~10× the effort. This sprint advances **both** differentiators, locking the executed hybrid witness in Days 1–3 and the machine-checked `lake build` on Day 4, with every remaining day touching a defining goal rather than a breadth grind.

### Ground truth the judge verified against the tree (load-bearing for the plan)
- `hybrid_sum/_core.c` is **identity** (`int square_sum(int x){return x;}`), not `x*x`; `app.py` `main()` is `pass` → **no CPython output to diff against** until the fixture is made semantically real (Day 3, PMAT-902).
- `xpile-oracle` is a ~195-line stub (only `PythonOracle` + `diff_stdout`); `xpile-agent` is a ~57-line `Budget`/`Session` stub with **no loop body**.
- `shim_part_for` has exactly six pending arms: **C + Shell real**; Cpp/Cuda/Python/Ruchy/Rust/Lean are gaps. `c_abi_type` maps `I64`/`Bool`→`c_int`, `F64`→`c_double` (float → `c_double`, **not** `c_float`).
- `elan`/`lake`/Lean4 are **installed locally** but **no `lake` step exists in CI**. Lean debt: **6 `sorry` across 5 files** (Notation 2; four others 1 each) + **~34 axiom lines** (PyIntArith alone ~13); 6 files import Mathlib.

## North star

Convert `xpile hybrid` from a static dispatch+reconcile+emit-shims pipeline (Phases 1/2/4, shipped at **PMAT-899**) into an **executing oracle on the C path**: compile the C side (`cc`), emit a buildable Cargo workspace whose `build.rs` cc-compiles `_core.c` and links the PMAT-899-emitted `unsafe extern "C"` shim, run the linked artifact, and **differential-check it byte-for-byte against CPython** on the `hybrid_sum` fixture — then close with a real **fail-closed deterministic agent-repair** increment. Demonstrating this even on the trivial `square_sum(int)->int` artifact is "the architecture's reason to exist," turning two claimed-but-unexecuted capabilities into demonstrable ones. The NumPy-style Python+C differential demo is the eventual payoff.

## Cadence rules

- One PMAT slice = one `feat/fix` PR + one `chore(release)` PR + one GitHub tag; **main is protected** behind the full CI gate (fmt, `cargo check --workspace`, `clippy -D warnings`, `pv lint` 0 ERRORS, `cargo-deny` advisories, `workspace-test`).
- Every day ships a tagged release **v0.1.598 (Day 1) .. v0.1.607 (Day 10)**; the GitHub tag ships regardless of crates.io.
- **crates.io publishes ONLY on Friday Day 4 (2026-06-26):** ~27 publishable crates in documented dependency order (`xpile-core` ~24th, `xpile` facade ~25th), each `cargo publish --dry-run` first, **abort-on-first-failure** (irreversible), LATE-Friday, **riding the last fully-green tag (Day-3 v0.1.600)** — not the same-day churny tree. On any dry-run failure: abort clean, name the failing crate, defer to 2026-07-03; the GitHub tag still ships.
- `pv lint contracts/` must be **0 ERRORS** every slice; advisory WARNINGS acceptable during prototype.
- `lake build` runs as a **SEPARATE advisory CI job** (like the kani job), **never** folded into the blocking publish gate, so Lean/Mathlib weight cannot stall the fast gate or the crates.io window.
- Gate-touching slices (contract-integrity, citation gate) are **sequenced, not parallel** (parallel-PR rebase-friction memory).
- Every `cc`/`gcc`/`rustc`/`python3`-dependent test **gates on toolchain presence with graceful-skip** (mirror `PythonOracle::available()`) so constrained CI stays green.
- Each slice leaves `cargo check --workspace` green; commit autonomously and frequently (xpile-local autonomy override).
- **Failure-isolating order:** the riskiest unknown (agent-repair convergence) lands **Day 9** so a stall there cannot retract the proven Days 2–3 north-star demo; the irreversible publish rides an already-green tag.

## Autonomy mechanism

A **durable daily cron (7-day auto-expiry)** drives EV-ranked self-pickup with no questions. A single 7-day cron does **not** cover the full 06-23..07-02 span, so **re-arm it on Day 1 AND again ~Day 7** so coverage never lapses through the window and the closing 07-03 Friday. Each firing: (1) emit a roadmap-completion **status line** (slices DONE, current vX.Y.Z, next EV pickup); (2) between slices run CI-poll / release-cut / correctness-hunt so nothing goes idle; (3) self-select the highest-EV item from the day's theme. **Never go idle** for the full sprint. Confirmation still required only for destructive ops (`reset --hard`, force-push, branch deletion, remote/deploy/Slack/email).

## Exit criteria

1. **North star executed:** `xpile hybrid hybrid_sum/ --verify` compiles the C side + emitted `unsafe extern "C"` Rust shim into a buildable workspace, links, runs, and differential-matches CPython on the (now real `x*x`) fixture; a `cc`+`rustc`+`python3`-gated end-to-end test + a golden-lock regression test pin the verdict.
2. **Agent-repair wired:** `xpile-agent` runs a bounded fail-closed `RepairLoop` that consumes an oracle Divergence, applies one deterministic rule, re-runs to Match within budget, and provably writes **no partial Rust** on exhaustion — Phase 6 demonstrated on one real failure class.
3. **Provability machine-checked:** `contracts/lean/` has a `lakefile` + pinned `lean-toolchain` and a separate advisory CI `lake build` job elaborating the sorry-free files; the 5 sorry files + axiom lines are honestly enumerated; sorry holes reduced **6 → ≤4** by real discharge (verified by `lake build`, not `grep`). "Provable" is no longer falsifiable by `grep sorry` for the demo's contracts.
4. **Paradigm progress:** `shim_part_for` has **4 of 6 arms real** (C, Shell, Ruchy, Rust); the matrix stays exhaustive with Cpp/Cuda/Python/Lean as explicit named gaps.
5. **Correctness:** the float-annotation-as-coercion divergence (epic #8–#11) is fixed (no E0308, differential-matches CPython) with an oracle fixture.
6. **R6 tail closed:** `C-FFI-SHELL-SUBPROCESS` authored and pv-lint-clean; `emit_shell_shim` cites it; the citation-integrity gate now scans **emitted** shim files.
7. **ABI ceiling lifted:** `decy-frontend` parses one wider C integer type and `c_abi_type` maps it to a distinct Rust FFI type instead of narrowing every `int` to `c_int`.
8. **Cadence held:** 10 daily tagged releases (v0.1.598..v0.1.607); main protected, full CI gate green each slice; crates.io batch ran **only** on Day 4, dep-order/dry-run-gated/abort-on-fail, riding green v0.1.600.
9. **Housekeeping:** PMAT-899 (+ all sprint ids) registered in `docs/roadmaps/roadmap.yaml`; the pre-commit roadmap-completeness warning cleared Day 1.
10. **Autonomy:** never idle across 06-23..07-02; cron re-armed Day 1 and ~Day 7; a status line each firing.
11. **`audit-design.md` truthed-up:** machine-checked Lean + a Run≥1 single-fixture hybrid differential witness, no overstated claims.
